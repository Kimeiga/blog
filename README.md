# Hakan Alpay’s blog

Source for **hakanalpay.com/blog**.

Astro + Markdown. Dark by default, light optional, golden-yellow accent (`#e3bd12`).

Includes archive, tags, local search, RSS/JSON Feed, issue-backed comments, licensed local photography, and migrated older posts. Editorial images are checked into `public/images`; content validation fails if a referenced local image is missing.

```bash
npm ci
npm run dev
npm run build
```

Agents: read [`AGENTS.md`](./AGENTS.md) and [`docs/EDITORIAL_STYLE.md`](./docs/EDITORIAL_STYLE.md).
